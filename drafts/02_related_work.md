# Related Work

\section{Related Work}
\subsection{AI Agents and Tool Use}
ReAct combines language-model reasoning with actions that access external information  [citation: yao2023]. This motivates a separation between intent interpretation and tool execution. Food Guardian adapts that general principle to inventory queries and meal planning; it does not claim to implement or outperform ReAct itself.
\subsection{Food Management and Domain Knowledge}
The Food Waste Index provides a measurement context for household waste  [citation: unep2024]. FDA consumer guidance distinguishes quality-oriented date labeling from broader storage considerations  [citation: fdafoodwaste]. These sources motivate contextual reminders rather than a safety guarantee. Local labeling guidance and ingredient-specific rules require separate verification before deployment in Taiwan.
\subsection{Research Gap}
The design hypothesis is that combining structured inventory information with contextual checks can improve the usefulness of recipe suggestions relative to an inventory-unaware baseline. A broader systematic literature review is still needed before asserting novelty across existing food-management systems.
